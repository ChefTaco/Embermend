# Embermend contracts

Versioned Zod 4 request, response and domain contracts for Embermend. The package
contains no backend or infrastructure credential imports. The generated OpenAPI
snapshot ships alongside its TypeScript declarations. External values remain
untrusted until their runtime schemas validate them.

The package is released with Embermend as an attested tarball on each GitHub release
(on npm once trusted publishing is enabled; see `docs/RELEASING.md`). Contract availability does not establish live remediation
capability; consult the repository's acceptance ledger.
